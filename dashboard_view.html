User Guide

Scanner & Import Scan paper documents, import files from your computer, or take a photo.
How to open the scanner
1Go to the Archive page.
2Select a folder from the tree on the left.
3Click the blue "Scan / Import" button at the top of the form.
Tab 1 — Network Scanner (eSCL / AirScan) + USB
1Type the scanner's IP address in the Scanner IP field, or click Find scanners to auto-detect.
2Click Test to confirm the scanner is reachable (dot turns green).
3Choose Color mode, DPI, Format, and Paper source.
4Click Scan. Add more pages with "Next Page" if needed.
5Click "Save to archive" to attach the scan to the document.
DPI guide: 200 DPI is fine for most documents. Use 300 DPI for text you plan to OCR. Avoid 600+ unless archival quality.
Connection dot: Grey = not tested · Green = connected · Red = unreachable.
Tab 2 — Import Files (upload from your computer)
1Switch to the "Import Files" tab inside the scanner modal.
2Click the upload area or drag files onto it. Accepted: PDF, images, Word, Excel.
3Optionally click "Extract Text (OCR)" to pull text from the file.
4Click "Save to archive".
Tab 3 — Camera (take a photo)
1Switch to the "Camera" tab.
2Click "Start Camera" — allow browser camera access if prompted.
3Click "Capture Photo". Repeat for multiple pages.
4Click "Save to archive".
On mobile, use the Use Phone Camera button for the best experience.
Archiving Documents Save scanned or imported files with metadata into the folder tree.
The 4-step workflow
1Pick folder
→
2Scan / Import
→
3Fill details
→
4Save
1Expand a department in the folder tree and click the target subfolder. It will highlight in blue.
2Click "Scan / Import" and attach your file (see Scanner tab for details).
3Fill in Topic / Subject (required), Date, Keywords, Importance, and Notes.
4Click "Save Document" to store, or "Send for Review" to forward to the next department.
Topic / Subject is the only required field. Fill in Keywords to help others find the document.
Editing an existing document
1Find the document in Inquiries.
2Click the document card to open the View modal, then click "Edit".
3Make your changes and click Save Document.
Inquiries & Search Find and view any archived document using filters and keyword search.
Search filters — how to use them
1Type a keyword in the search box to filter by topic, keywords, or notes.
2Use the Department and Folder dropdowns to narrow to a specific location.
3Set a date range to filter by when the document was archived.
4Click "Search" or press Enter. Results appear below.
Grid view — results as cards.
List view — compact table. Use the toggle buttons next to the result count to switch.
Folder Browser Understand and manage the department and folder structure.
Understanding the folder structure
1Top level = Departments (e.g. HR, Finance). These cannot be deleted.
2Second level = Main folders inside a department.
3Third level = Subfolders (child folders) inside a main folder.
Creating a new main folder (admin only)
1Go to Folder Browser and click "New Main Folder".
2Enter the folder name, select the department, and optionally choose a parent folder.
3Click "Save". The folder appears in the tree immediately.
Regular users can create subfolders from the Archive page using the folder action buttons.
